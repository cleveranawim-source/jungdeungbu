# 디자인 시스템 — "차분하고 단정한 교회"

다음 화면을 만드는 사람은 이 문서와 `src/ui/theme.css` 만 읽으면 된다.

## 1. 방향

- **주보를 펼친 것처럼 차분하고 단정하게.** 밝은 모드는 아이보리 바탕에 흰 카드, 어두운 모드는 깊은 남색 바탕에 크림색 글자다.
- 글자와 손이 가는 곳은 **남색 하나**(`--ink`, `--accent`). 어두운 모드에서는 버튼을 **금색 채움 + 남색 글자**로 뒤집는다.
- **금색**은 작게만 쓴다: 날짜·강조 숫자 글자(`--accent-text`), 선택된 탭 밑줄과 첫 화면의 짧은 선(`--gold`). 금색 면은 어두운 모드의 `--accent` 채움(버튼·체크된 출석·출석 달력)뿐이고, 그 밖에 금색 면이나 큰 금색 글자는 만들지 않는다.
- 제목(화면 제목 h1, 카드 제목 h2, 말씀 제목, 첫 화면 "중등부")은 **고운바탕**, 나머지 모든 글자는 **프리텐다드**. 두 글꼴 모두 앱에 파일로 싣는다(외부 글꼴 서버 없음).
- 모양은 **부드러운 카드**: 살짝 둥근 흰 면 + 얇은 선, 그림자 없음. 장식은 금색 짧은 선 하나뿐. 해·빛줄기·그라데이션·십자가 그림은 화면에 넣지 않는다(십자가는 앱 아이콘에만).
- 중학생이 한 손으로 쓴다: 할 일은 화면 아래(엄지 닿는 곳), 터치 영역 48px, 본문 17px.
- 2026-11-10 이승열 P가 시안(글꼴 4종 · 색 4종 · 모양 3종)을 비교해 고른 방향이다. 앞의 "주일 아침 햇살"(귤색·Jua)은 폐기했다.

## 2. 파일 구성

| 파일 | 내용 |
|---|---|
| `src/ui/theme.css` | **토큰만**(CSS 변수). 밝은/어두운 모드, 움직임 줄이기 |
| `src/ui/base.css` | 요소 기본값(body·h1~h3·a·초점 고리·`.sr-only`) |
| `src/ui/*.tsx` + `*.module.css` | 공통 컴포넌트. **스타일은 CSS Modules**, 컴포넌트 옆 `이름.module.css` |
| `src/ui/icons.tsx` | 인라인 SVG 아이콘(`<Icon name="home" />`) |
| `src/app/*` | 앱 셸(라우터·역할·탭 바·토스트·오프라인 띠·랜딩·잘못된 링크) |

- UI 프레임워크·Tailwind 없음. 새 화면도 `화면.tsx` + `화면.module.css`.
- 컴포넌트 CSS 에 **색 hex·rgb 를 직접 쓰지 않는다.** 크기도 가능하면 토큰(`var(--space-4)`)으로.
- `theme.css` 에 새 토큰이 필요하면 밝은/어두운 두 값과 대비를 함께 적어 넣는다.

## 4. 컴포넌트 규칙

### Screen (`src/ui/Screen.tsx`)
`<Screen title sub actions tabBar>` — 모든 화면의 틀. h1 은 Screen 만 그린다. 탭 바를 쓰는 화면은 `tabBar` 로 넘겨야 내용이 탭 바 뒤로 숨지 않는다. 내용(`main`)은 세로로 16px 간격.

### Card (`src/ui/Card.tsx`)
`<Card title tone as>` — 묶음 하나. `title` 은 h2(20px).
- `default`: 흰 면 + 얇은 선, 그림자 없음. 대부분(홈의 이번 주 말씀 카드 포함).
- `accent`: `--accent-soft` 면. 화면에 하나 이하, 조용한 강조에만.
- `quiet`: 점선. 개발용·보조.
- 카드 안에 카드를 넣지 않는다. 목록의 각 줄은 카드가 아니라 카드 안의 줄(구분선 `--line`)로.

### Button (`src/ui/Button.tsx`)
`<Button variant size block icon busy>` / 화면 이동은 `<LinkButton href>`.
- `primary`(남색 채움, 어두운 모드 금색 채움): 화면에서 가장 중요한 행동 **하나**. `secondary`(흰 면 + `--line` 선 + 남색 글자): 그 밖의 행동. `ghost`(글자만): 덜 중요한 행동·줄 안 행동. `danger`: 되돌릴 수 없는 삭제(확인 뒤).
- 높이 48px(`sm` 44px, `lg` 56px). 아이콘만 있는 버튼은 `aria-label` 필수, 크기 44×44 이상.
- 처리 중엔 `busy`(누를 수 없음 + 동그라미). 버튼 글자는 동사로 끝나는 짧은 말("올리기", "저장", "에뮬레이터 로그인").

### Field / TextArea (`src/ui/Field.tsx`)
`<Field label hint error … />`, `<TextArea label showCount maxLength … />`.
- 라벨은 늘 보인다. placeholder 는 예시일 뿐 라벨 대신이 아니다.
- 오류는 `error` 로: 빨간 테두리 + 아이콘 + 문구(화면 읽기가 바로 읽음). 색만으로 알리지 않는다.
- 글자 크기 17px(16px 미만이면 iOS 가 확대한다).

### TabBar (`src/app/TabBar.tsx`)
`<TabBar items={[{ key, label, icon }]} current onChange label />` — 하단 고정, 높이 56px + 아래 안전 영역, 가운데 640px.
- 탭은 `role="tab"`, `aria-selected`. 좌우 화살표·Home·End 로 옮겨 간다.
- 선택된 탭: 아이콘·라벨 모두 굵게 `--ink`, 아래에 3×18px `--gold` 밑줄이 펼쳐진다. 나머지는 `--muted`.
- 라벨은 1~2글자(홈·주보·말씀·기도·나 / 출석·우리 반·기도·주보·관리). 탭은 5개까지.

### Toast (`src/app/Toast.tsx`)
`const { show } = useToast(); show('링크를 복사했어요'); show(describeError(e), 'error');`
- `info`(반전 남색, 체크 아이콘, 3.5초): 한 일을 확인해 주는 말. `error`(빨강, 6초): 실패와 해결 방법.
- 탭 바 바로 위에 뜬다. 같은 문구는 쌓이지 않고 최대 3개. ✕ 로 닫는다.
- Firestore 오류는 항상 `describeError(e)` 를 거친다(`permission-denied` / `unavailable` 문구가 정해져 있다).

### 그 밖
- `EmptyState`(`src/ui/EmptyState.tsx`): 빈 목록·준비 중. 점선 + `--accent-soft` 아이콘 동그라미 + 제목(지금 상태) + 설명(다음에 할 일) + 버튼 하나(선택).
- 첫 화면(`Landing`)·잘못된 링크(`InvalidLink`): 고운바탕 제목 + 40×2px `--gold` 짧은 선 + 안내. 이 짧은 선이 앱의 유일한 장식이며 다른 화면에 늘리지 않는다.
- `OfflineBar`(`src/app/OfflineBar.tsx`): App 이 맨 위에 한 번 둔다. 화면에서 따로 넣지 않는다. `useOnline()` 도 내보낸다.
- `InvalidLink`(`src/app/InvalidLink.tsx`): "선생님께 링크를 다시 받아주세요" 한 화면. 학생 문서가 없거나 비활성일 때도 이걸 그대로 쓴다.
- `EmuLogin`(`src/app/EmuLogin.tsx`): 에뮬레이터 로그인 폼. `USING_EMULATOR` 가 아니면 아무것도 그리지 않으므로 조건 없이 넣는다.
- `BulletinView`(`src/ui/BulletinView.tsx`): 주보 한 장. 종이 주보처럼 카드 하나 안에 예배 순서(순서 이름 ······ 맡은 사람, 점선 이음)·찬양·말씀·광고. 빈 구역은 그리지 않는다. 설교 링크는 선택 prop `sermonHref` 가 있을 때만.
- `AttendanceCalendar`(`src/ui/AttendanceCalendar.tsx`): 학기 주일만, 달마다 한 줄. 출석 = `--accent` 채운 동그라미(날짜가 안에), 결석·기록 없음 = 같은 옅은 점(탓하지 않게 겉모습은 같고, 화면 읽기 이름만 다르다). 누르는 칸이 아니다.
- `CelebrationBanner`(`src/ui/CelebrationBanner.tsx`): 생일 주간·연속 출석 4주마다. `--accent-soft` 면의 띠 하나(모서리 12px), 강조 숫자는 `--accent-text`, 움직임 없음. 축하 문구 안 이모지(🎂 🔥)만 허용. 규칙은 `src/lib/celebrate.ts`.
- 아이콘: `src/ui/icons.tsx` 의 `<Icon name />` 만. 24 격자·선 2px·둥근 끝(Lucide 모양). 새 아이콘도 같은 규칙으로 여기에 추가. 글자 옆 아이콘은 화면 읽기에서 숨겨지고(기본), 아이콘만으로 뜻을 전하면 `label` 을 준다. **이모지를 아이콘으로 쓰지 않는다**(축하 문구 안 이모지는 괜찮다).

## 5. 문구 톤

- 존댓말 "-요" 체, 짧게. 학생에게 친구 같은 선생님 말투: "선생님께 전했어요", "이번 주 주보가 아직 없어요".
- 꾸짖거나 판단하지 않는다. 결석·실수를 탓하지 않는다("왜 안 왔어?" X). 출석이 없으면 그냥 빈칸.
- 신앙 표현은 내용(설교·기도 제목)에 맡기고, 화면 문구는 설교하지 않는다("하나님이 기뻐하세요!" 같은 말 X).
- 행동 이름은 끝까지 같게: 버튼 "올리기" → 토스트 "올렸어요". "제출", "확인" 같은 뭉뚱그린 말 대신 무슨 일이 일어나는지.
- 오류는 무슨 일이 생겼고 어떻게 하면 되는지: "연결이 끊겼어요. 다시 연결되면 저장돼요". 사과문·애매한 말("오류가 발생했습니다") X.
- 빈 화면은 다음 행동으로 이끈다. 정해진 문구(스펙)는 바꾸지 않는다.
- 문장 사이 `·` 로 메타 정보를 줄줄이 잇지 않는다(날짜와 이름은 줄을 나누거나 쉼표).

- [ ] 화면은 `<Screen>` 으로 감쌌고 h1 은 하나다. 탭 화면이면 `tabBar` 로 넘겼다.
